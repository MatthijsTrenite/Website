# matthijstrenite.com

Portfolio website built with Astro + Tailwind CSS.

## Development

```bash
npm run dev     # Start dev server
npm run build   # Build for production
npm run preview # Preview production build
```

## Content

Projects are managed via MDX files in `src/content/projects/`. Each project has frontmatter for metadata and MDX body for the project page content.

Images go in `public/images/projects/[project-slug]/`.
